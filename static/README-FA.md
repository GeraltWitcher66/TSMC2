# راهنمای نسخه استاتیک — فیلتر بورس ایران

این نسخه یک صفحه کامل است که همه‌ی محاسبات را داخل مرورگر خودتان انجام می‌دهد. هیچ سروری لازم نیست و فقط داده‌ی بازار از منبع‌های عمومی خوانده می‌شود.

## برای استفاده روزمره

۱. لینک برنامه را که در اختیارتان گذاشته شده در مرورگر باز کنید.
۲. **اگر VPN روشن است، آن را خاموش کنید.** با VPN روشن، منبع‌های داده‌ی بورس در دسترس نیستند و صفحه پیام خطا نشان می‌دهد.
۳. مرورگر لازم: **Chrome نسخه ۱۰۹ یا بالاتر** یا **Firefox نسخه ۱۱۵ یا بالاتر**. مرورگرهای قدیمی‌تر صفحه را ناقص نشان می‌دهند.
۴. فهرست‌های «حقیقی»، «زرد/نارنجی» و «دلخواه» در حافظه‌ی همان مرورگر ذخیره می‌شوند؛ تغییرات را در همان مرورگر و همان دستگاه خواهید دید.
۵. برای رفتن به هر بخش، از تب‌های بالای صفحه استفاده کنید. نشانی هر تب در انتهای لینک (بعد از `#`) ثبت می‌شود، پس می‌توانید لینک همان بخش را ذخیره کنید.

## اگر پیام خطا دیدید

- **«اتصال به داده بورس برقرار نشد. اگر VPN روشن است خاموشش کنید.»** یعنی مرورگر نتوانسته به منبع داده وصل شود. VPN یا افزونه‌ی تغییر مسیر را خاموش کنید و دکمه‌ی «تلاش دوباره» را بزنید.
- اگر بعد از خاموش کردن VPN باز هم خطا بود، اتصال اینترنت را بررسی کنید و صفحه را یک بار تازه کنید (F5).
- اگر جدول برای چند نماد خالی است، معمولاً داده‌ی همان نماد در منبع منتشر نشده است؛ ستون توضیح، دلیل را نشان می‌دهد. این وضعیت با دوباره‌سازی جدول ممکن است رفع شود.

## نکته‌های مهم

- این برنامه فقط نمایش و غربالگری است و توصیه‌ی خرید یا فروش نیست.
- آخرین تاریخ معاملاتی از خود داده‌ی بازار خوانده می‌شود؛ تعطیلی بازار به‌تنهایی به معنی قدیمی بودن داده نیست.
- داده‌ها فقط از منبع‌های عمومی بازار خوانده می‌شوند و هیچ اطلاعاتی از شما ارسال یا ذخیره نمی‌شود.

## ساخت و انتشار (برای نگه‌دارنده پروژه)

```bash
npm ci
npm ci --prefix static
npm run build --prefix static
```

خروجی در `static/dist` ساخته می‌شود و برای آپلود آماده است. فایل `index.html` از مسیرهای نسبی استفاده می‌کند، بنابراین هم در ریشه‌ی دامنه و هم در زیرپوشه‌ی GitHub Pages کار می‌کند. با هر push به شاخه‌ی `main`، گردش‌کار `.github/workflows/pages.yml` همین خروجی را می‌سازد و روی GitHub Pages منتشر می‌کند.

برای اجرای آزمون‌ها:

```bash
npm test --prefix static
```
